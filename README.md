# 🌸 Number Crush 🎮

🧠✨ **Number Crush** is a fast and addictive mental math game built using **HTML, CSS, and JavaScript**.
Players solve quick math challenges before the timer runs out, making learning fun while improving:

* ⚡ Calculation Speed
* 🎯 Concentration & Focus
* 🧩 Problem-Solving Skills
* 🧠 Memory Power
* 🚀 Reflexes & Quick Decision Making

The game features a soft pastel UI, smooth gameplay, score tracking, high-score saving, and increasing difficulty to keep players engaged and mentally active.

---

## 💻 Technologies Used

* HTML5
* CSS3
* JavaScript

---

## 🎮 Features

* Random Math Questions
* Countdown Timer
* Score & High Score System
* Responsive Design
* Smooth UI Effects
* Beginner Friendly Code
